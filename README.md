# Membran Digital

> Building local-first, privacy-focused utility software for modern engineering and security-conscious professionals.

---

### 🛡️ About Us

**Membran Digital** is an independent software studio dedicated to building desktop utilities where user sovereignty, data security, and offline reliability come first. We believe modern software shouldn't require aggressive telemetry, mandatory cloud tie-ins, or privacy trade-offs.

---

### 🚀 Key Products

#### 🔒 [NoCapture](https://membran.digital)
An OS-level desktop privacy utility designed to shield your active windows and sensitive displays from unauthorized screen capture, activity monitoring tools, and background AI screen scraping.
* **Platforms:** Windows, Linux, macOS
* **Key Features:** Real-time display cloaking, zero telemetry, local process isolation.
* **Repository:** [`H-was1/nocapture`](https://github.com/H-was1/nocapture)

#### ⚡ [Viggen](https://membran.digital)
An air-gapped, local-first release and handover tool engineered for industrial automation environments.
* **Use Case:** Site handovers, FAT/SAT proof-of-work documentation, automated PLC backups, and signed evidence packages.

---

### ⚙️ Core Engineering Principles

* **Local-First Architecture:** Your data stays on your hardware. Everything functions entirely offline without remote cloud dependencies.
* **Zero Telemetry:** No tracking pixels, no event logging endpoints, no phone-home mechanisms.
* **Lightweight & High-Performance:** Native system hooks and optimized cross-platform runtimes built for minimal memory footprint.
